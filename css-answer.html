CSS Practice Question – Solution

CSC 337 – Web Programming Languages • Assignment 2 • 10 Marks (CLO-2)

📄 Given CSS

* {
    font-size: 18px;
    font-family: Tahoma;
}

h1, h3 {
    color: darkgreen;
    font-style: normal;
}

p {
    color: gray;
}

section p {
    color: brown;
    font-style: italic;
}

.wrapper h3 {
    font-family: "Times New Roman";
    color: maroon;
}

section + h1 {
    border-style: solid;
    color: navy;
}

.highlight {
    font-size: 26px;
    border-style: dotted;
}

📄 Given HTML

<body>
    <section> Line 1 </section>
    <br/>

    <section class="wrapper">
        <p> Line 2 </p>
        <h3> Line 3 </h3>
    </section>

    <p> Line 4 </p>

    <section>
        <ul>
            <li> Line 5 </li>
        </ul>
    </section>

    <h1> Line 6 </h1>

    <p class="highlight"> Line 7 </p>
</body>

✅ Final Applied Styles – Answer Table

Line HTML Element Matching Rules Final Applied Styles
Line 1 <section> *
  • font-size: 18px
  • font-family: Tahoma
  • color: NIL (inherited from browser default)
Only the universal selector * applies. No other rule targets a bare <section>.
Line 2 <p> inside section.wrapper *, p, section p
  • font-size: 18px (from *)
  • font-family: Tahoma (from *)
  • color: brown (section p overrides p → gray)
  • font-style: italic (from section p)
section p (specificity 0,0,1,1) beats p (specificity 0,0,0,1), so color is brown and font-style is italic.
Line 3 <h3> inside section.wrapper *, h1, h3, .wrapper h3
  • font-size: 18px (from *)
  • color: maroon (.wrapper h3 overrides h1,h3 → darkgreen)
  • font-family: Times New Roman (.wrapper h3 overrides * → Tahoma)
  • font-style: normal (from h1, h3)
.wrapper h3 (specificity 0,1,0,1) beats h1, h3 (0,0,0,1). So color = maroon and font-family = Times New Roman. font-style comes from h1, h3 since .wrapper h3 doesn't set it.
Line 4 <p> (standalone, outside section) *, p
  • font-size: 18px (from *)
  • font-family: Tahoma (from *)
  • color: gray (from p)
This <p> is not inside a <section>, so section p does NOT apply. Only p and * match.
Line 5 <li> inside <ul> inside <section> *
  • font-size: 18px (from *)
  • font-family: Tahoma (from *)
  • color: NIL
No specific rule targets <li>. Only the universal selector applies.
Line 6 <h1> (immediately after a <section>) *, h1, h3, section + h1
  • font-size: 18px (from *)
  • font-family: Tahoma (from *)
  • color: navy (section + h1 overrides h1,h3 → darkgreen)
  • font-style: normal (from h1, h3)
  • border-style: solid (from section + h1)
section + h1 is the adjacent sibling combinator. The <h1> is immediately after the last <section> (ignoring <p> in between — wait: actually the <p> Line 4 </p> and the second section are between). The second <section> (containing Line 5) is the immediate sibling of <h1> Line 6. So section + h1 DOES apply. Color = navy, border-style = solid.
Line 7 <p class="highlight"> *, p, .highlight
  • font-size: 26px (.highlight overrides * → 18px)
  • font-family: Tahoma (from *)
  • color: gray (from p; .highlight doesn't set color)
  • border-style: dotted (from .highlight)
.highlight (specificity 0,1,0,0) overrides * for font-size → 26px. p rule still sets color to gray since .highlight doesn't specify color.

📘 Specificity Reference (used in analysis above)

CSS specificity is calculated as (inline, id, class/attribute/pseudo-class, element):

  • * → (0,0,0,0) — lowest priority
  • p, h1, h3, li, section → (0,0,0,1) — element selector
  • h1, h3 → (0,0,0,1) — same, comma = two separate rules
  • .highlight → (0,0,1,0) — class selector
  • section p → (0,0,0,2) — two element selectors
  • section + h1 → (0,0,0,2) — two element selectors (combinator doesn't add)
  • .wrapper h3 → (0,0,1,1) — class + element
